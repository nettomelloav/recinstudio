# Rec In Studio

**Sua pós no piloto automático, dentro do DaVinci Resolve.** Plugin para o DaVinci Resolve Studio (R$ 97,00, pagamento único via Pix,
licença vitalícia) com 7 módulos: correção de legendas, corte de silêncios, ferramentas da transcrição, sync de áudio e
multicâmeras, sound design, busca de imagens e prévia para redes com safe zones.

- Página: https://nettomelloav.github.io/recinstudio/
- Comprar: https://nettomelloav.github.io/recinstudio/#comprar
- Download Mac (sempre a versão mais nova; pede a chave de licença): https://github.com/nettomelloav/recinstudio/releases/latest/download/RecInStudio.pkg
- Windows: em breve

## Instalar

1. Dê dois cliques em `RecInStudio.pkg`. Se o macOS disser que não pode abrir:
   **Ajustes do Sistema › Privacidade e Segurança › Abrir Mesmo Assim** (o instalador não tem assinatura da Apple).
2. No DaVinci Resolve Studio: **Workspace › Workflow Integrations › Rec In Studio**.
3. Cole a chave de licença (começa com `RIS1-`) e clique em **Ativar**.

Guia completo: [GUIA.md](GUIA.md).

## Requisitos

- Mac compatível com o DaVinci Resolve Studio 21
- DaVinci Resolve **Studio** 21 (testado na 21.2)

Desenvolvido por Netto Mello Videomaker. DaVinci Resolve é marca da Blackmagic Design; o Rec In Studio é independente.
